# RH-Sistema | Sistema de Gestão de Recursos Humanos

O **RH-Sistema** é uma aplicação web desenvolvida para centralizar, organizar e simplificar os principais processos de gestão de recursos humanos de uma organização.

Desenvolvido com PHP, MySQL, HTML, CSS e JavaScript, o sistema apresenta uma arquitetura modular, permitindo gerir informações de funcionários, departamentos, cargos, presenças, férias, remunerações, recrutamento e avaliações de desempenho.

## 🚀 Principais Funcionalidades

- 👥 **Gestão de Funcionários:** Cadastro, atualização e acompanhamento dos dados dos colaboradores.
- 🏢 **Departamentos e Cargos:** Organização da estrutura administrativa da empresa.
- 📅 **Gestão de Férias:** Solicitação, aprovação, rejeição e acompanhamento de férias.
- ⏰ **Controlo de Presenças:** Registo e acompanhamento da assiduidade.
- 💰 **Folha de Pagamento:** Gestão de salários, pagamentos e recibos.
- 📊 **Avaliação de Desempenho:** Registo e acompanhamento das avaliações dos colaboradores.
- 💼 **Recrutamento:** Gestão de vagas, candidatos e entrevistas.
- 📁 **Gestão Documental:** Organização e partilha de documentos.
- 🔔 **Notificações:** Comunicação de informações e atividades relevantes.
- 📈 **Relatórios:** Consulta e exportação de informações administrativas.
- 🔐 **Controlo de Acesso:** Gestão de permissões baseada em perfis de utilizador.
- 🛡️ **Auditoria:** Registo de atividades realizadas no sistema.
- 💾 **Backups:** Funcionalidades de cópia de segurança, com restauração ainda em desenvolvimento.

## 👤 Perfis de Utilizador

O sistema contempla seis níveis de acesso:

1. Super Administrador
2. Administrador de Recursos Humanos
3. Recursos Humanos
4. Gestor
5. Funcionário
6. Auditor

Cada perfil possui permissões específicas, de acordo com as suas responsabilidades.
